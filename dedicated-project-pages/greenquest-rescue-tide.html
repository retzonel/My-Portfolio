Overview

GreenQuest: Rescue Tides is an educational simulation game set in Lagos, built to teach flood response and environmental awareness through interactive gameplay.

Beyond core systems, I later redeveloped large parts of the project from scratch — replacing the existing architecture with a modular, optimized codebase, improving UX/UI, reducing APK size, and integrating new gameplay mechanics.

Highlights

  • Published and live on the Google Play Store
  • Redeveloped core architecture into a modular, optimized codebase
  • Reduced APK size and reworked UX/UI across the app
  • Integrated new gameplay mechanics on top of the flood-simulation core

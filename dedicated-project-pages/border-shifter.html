Overview

BorderShifter is a 2D puzzle/strategy game built for the Pan-African Game Jam 2026 at Lagos Games Week, where the core mechanic is teleporting across shifting borders to reunite divided countries.

Built in collaboration with DiamondMind under the jam's constraints, it took 2nd place at the event.

Highlights

  • 🥈 2nd Place — Pan-African Game Jam, Lagos Games Week 2026
  • Designed a border-teleportation puzzle mechanic as the core loop

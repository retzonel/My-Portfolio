Overview

Agent Info is a short narrative game built with the Creotly Studio team for the GameUp Africa game jam, themed around identifying and resisting disinformation.

The game took 1st place at the jam. I worked on gameplay systems and ShaderGraph-driven visual polish under a tight jam deadline.

Highlights

  • 🥇 1st Place — GameUp Africa game jam for democracy, 2024
  • Built core gameplay logic and visual effects in a compressed jam timeline
  • Collaborated as part of the Creotly Studio team
